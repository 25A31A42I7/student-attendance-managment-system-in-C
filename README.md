# Student Attendance Management System

A simple, terminal-based CLI application written in C to manage and track student attendance using binary file handling.

## Features
- **Persistent Storage**: Uses `attendance.dat` to save data between sessions.
- **Add Students**: Register new students with unique IDs.
- **Mark Attendance**: Increment attendance count for specific students by ID.
- **View Records**: Display a formatted table of all student data.
